# Portafolio

Sitio personal de Ricardo: quién soy, mis proyectos y lo que sé.

HTML, CSS y JS a mano, sin dependencias ni paso de build.

## Correr en local

Abrir `index.html` en el navegador, o servir la carpeta:

```
npx serve .
```

## Publicar

Cualquier hosting estático sirve tal cual (Vercel, Netlify, GitHub Pages):
la raíz del sitio es la raíz del repo.

## Editar

- Textos y proyectos: `index.html`
- Colores y estilos: variables al inicio de `styles.css`
